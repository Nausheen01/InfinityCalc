# 🧮 InfinityCalc – Advanced JavaScript Calculator

InfinityCalc is a modern and responsive calculator web app built using **HTML, CSS, and JavaScript**.
It includes basic, scientific, and interactive features with a clean UI and smooth user experience.

## ✨ Features

* ➕ Basic arithmetic operations
* 🧠 Scientific calculator functions
* 🌙 Dark / Light mode
* ⌨️ Keyboard support
* 🕘 Calculation history
* 🎙️ Voice input
* 🔊 Button sound effects
* 📱 Fully responsive design
* 🎨 Smooth UI animations
* ⚠️ Error handling for invalid inputs
